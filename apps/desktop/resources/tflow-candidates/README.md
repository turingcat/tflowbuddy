# TFlow desktop brand candidates

English | [中文](README.zh.md)

These three candidates are retained as review assets. Candidate 03 is now selected and has been applied to the formal `apps/desktop/resources` files. Each folder contains an SVG source and PNG previews.

The directions use the visual cues visible on `tflow.online`: a teal and blue interface palette, an API gateway that connects multiple model providers, and a short TFlow wordmark that must remain legible in a desktop rail and application icon.

## Jev Score rubric

The rubric follows TypeSafe Jev Score semantics: each ordered level describes a concrete outcome, and the weighted result is a ranking aid rather than an automatic decision. No TypeSafe API credential is configured in this workspace, so the values below are an offline structured evaluation using the same Score question and probability-weighted calculation. They are intentionally advisory; the final selection remains with the product owner.

Dimensions are scored from 0 to 4: desktop legibility, TFlow fit, distinctiveness, and production readiness. Weights are 35%, 30%, 20%, and 15%.

## Candidate directions

- `01-flowline`: a compact T built from two flowing strokes, intended to echo traffic moving through an API gateway.
- `02-nodes`: three connected nodes form a T, making the provider-routing idea explicit at small sizes.
- `03-badge`: a high-contrast TFlow wordmark inside a rounded signal badge, optimized for a recognizable desktop tile.
