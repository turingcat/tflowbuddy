# TFlow 桌面品牌候选方案

[English](README.md) | 中文

这三个候选方案保留为评审素材。现已选定方案 03，并应用于正式的 `apps/desktop/resources` 文件。每个目录包含 SVG 源文件和 PNG 预览。

设计方向取自 `tflow.online` 的视觉元素：青绿与蓝色界面配色、连接多个模型供应商的 API 网关，以及需要在桌面侧栏和应用图标中保持清晰的简短 TFlow 字标。

## Jev Score 评分规则

评分规则沿用 TypeSafe Jev Score 语义：每个有序等级描述具体结果，加权结果仅辅助排序，不自动决定方案。本工作区未配置 TypeSafe API 凭据，因此下列数值是采用相同 Score 问题和概率加权计算方式进行的离线结构化评估。评分仅供参考，最终选择由产品负责人决定。

各维度按 0 至 4 分评分：桌面辨识度、TFlow 契合度、差异性和生产可用性。权重依次为 35%、30%、20% 和 15%。

| 候选方案 | 辨识度 | TFlow 契合度 | 差异性 | 生产可用性 | 加权得分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 01-flowline | 4 | 4 | 3 | 4 | 3.85 / 4 |
| 02-nodes | 4 | 3 | 4 | 3 | 3.55 / 4 |
| 03-badge | 3 | 4 | 3 | 4 | 3.55 / 4 |

## 候选方向

- `01-flowline`：由两条流动笔画组成的紧凑 T 字形，呼应流量通过 API 网关的过程。
- `02-nodes`：三个相连节点构成 T 字形，在小尺寸下明确表达供应商路由的含义。
- `03-badge`：圆角信号徽章内的高对比度 TFlow 字标，强调桌面图标的辨识度。
